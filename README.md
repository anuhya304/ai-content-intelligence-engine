# AI Content Intelligence Engine

An AI-powered content generation platform that helps users research
trending topics, generate social media scripts, and create engaging
hooks and calls-to-action.

## Features

- Niche and target-audience based content discovery
- Trend research using Firecrawl
- AI-generated social media scripts
- Multiple content frameworks
- Hook and CTA generation
- Support for Instagram, YouTube, TikTok, X/Twitter, and LinkedIn
- Multiple content goals and tones
- Save and manage generated scripts
- Responsive React interface

## Tech Stack

- React
- TypeScript
- Vite
- Supabase
- Tailwind CSS
- Firecrawl
- AI APIs
- Vitest
- Playwright

## Workflow

Discovery → Research → Script Generation → Hook & CTA Generation → Save
